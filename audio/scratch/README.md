# Scratch voiceover

Place rough recordings here before final mix. Filenames expected by [TASKS.md](../TASKS.md):

| File | Script |
| ---- | ------ |
| `teaser.m4a` or `teaser.wav` | [scripts/teaser.md](../scripts/teaser.md) |
| `deepdive.m4a` or `deepdive.wav` | [scripts/deepdive.md](../scripts/deepdive.md) |

**Workflow:** Record on phone or headset → export lossless if possible → listen at 1× and 1.5× → cut lines that drag in the markdown scripts → re-record → move finals to `audio/final/` when ready for DaVinci.

Git ignores `*.wav`, `*.m4a`, etc. in parent `.gitignore`; only this README and `.gitkeep` travel in git.
