\chapter{Architectures with better asymptotics}

\section{State-space models (e.g.\ Mamba)}

Selective state-space models update a hidden state across time with linear complexity in sequence length $n$
under typical formulations \cite{gu2023mamba}. They trade the explicit all-pairs attention matrix for recurrent
state dynamics.

\section{Long convolutions (e.g.\ Hyena)}

Convolutional layers with long kernels can be implemented in $\Theta(n \log n)$ time via FFTs in appropriate
settings \cite{poli2023hyena}.

\section{Linear attention}

Kernelized reformulations can reorder computations to $\Theta(n d^2)$ under suitable feature maps $\phi$
\cite{katharopoulos2020transformers}, trading expressivity or approximation quality against speed.

\section{Hybrids}

Many practical stacks interleave efficient layers (SSM, convolution, linear attention) with a smaller number
of dense or windowed attention layers to recover retrieval-like behavior.
