\chapter{Annotated reading list}
\label{app:reading}

Thirty papers, organised by topic, with one paragraph each on what to read
them \emph{for}. Aimed at someone who wants to go deeper than this book
and is choosing what to read next.

\section*{Foundations: from RNN to Transformer}

\paragraph{\citet{elman1990finding}.}
Introduces the simple recurrent network as a learnable dynamical system over
distributed representations. Read it for the historical proof that ``memory''
can live in a hidden state updated every step---the baseline recurrence later
replaced by attention.

\paragraph{\citet{hochreiter1997lstm}.}
Defines LSTM with forget, input, and output gates so gradients can flow across
time through an additive cell state. Read it when you want the authoritative
statement of why gating beats vanilla \(\tanh\) RNNs on long dependencies.

\paragraph{\citet{bahdanau2014attention}.}
Adds differentiable soft alignment from decoder to encoder states for
sequence-to-sequence MT. Read it to see attention \emph{before} self-attention:
weights over positions are learned from two streams of hidden states.

\paragraph{\citet{vaswani2017attention}.}
Stacks self-attention and position-wise FFNs, removes recurrence, and argues for
parallelism and path length. Read it as the architectural pivot this entire book
orbit---everything else measures distance from this baseline.

\paragraph{\citet{devlin2019bert}.}
Bidirectional masked-language-model pre-training over Transformer encoders.
Read it for encoder-only contrast with GPT-style causal LMs and for WordPiece
tokenisation context.

\section*{Scaling: how big and how much}

\paragraph{\citet{kaplan2020scaling}.}
Empirical power laws linking loss to model size, data, and compute; argues for
scaling up \(N\) within budget. Read it to understand the pre-Chinchilla mental
model and why inference costs were not centralised in that era.

\paragraph{\citet{hoffmann2022training}.}
Derives compute-optimal allocation with roughly \(20\times\) tokens per
parameter at large scale (``Chinchilla''). Read it together with Kaplan to see
the explicit trade-off flip toward smaller models trained longer.

\paragraph{\citet{wei2022emergent}.}
Catalogues tasks where capability jumps appear only beyond a scale threshold.
Read it for the empirical phenomenon; pair with sceptical metric-design
critiques elsewhere when interpreting ``emergence.''

\paragraph{\citet{sardana2024beyond}.}
Revisits scaling laws when inference cost matters---not only training FLOPs.
Read it as the bridge from Chapters~\ref{ch:kaplan}--\ref{ch:what-scaling-omits} (scaling laws) to serving economics in Chapters~\ref{ch:flashattention}--\ref{ch:kv-cache}.

\section*{Engineering: making attention practical}

\paragraph{\citet{dao2022flashattention}.}
Tiled attention that reduces \textsc{hbm} round-trips and improves wall-clock
without changing numerics. Read it before FA-2/3 so you understand IO-awareness
as the core idea.

\paragraph{\citet{dao2023fa2}.}
Reorders work across warps and improves occupancy for attention on modern GPUs.
Read it for the incremental but real throughput wins over FA-1.

\paragraph{\citet{shah2024fa3}.}
Pushes low-level fusion further on Hopper-class hardware. Read it to see how
hardware generations shift what ``optimal'' kernel design means.

\paragraph{\citet{shazeer2019mqa}.}
Shares one key and one value head across all query heads to shrink KV cache.
Read it as the cleanest memory/compute knob before grouped variants.

\paragraph{\citet{ainslie2023gqa}.}
Interpolates between MHA and MQA by grouping query heads per KV head. Read it
for how Llama-class models recover some expressivity while saving cache.

\paragraph{\citet{kwon2023vllm}.}
PagedAttention and continuous batching for shared KV storage in inference.
Read it when turning memory formulas into a multi-tenant serving story.

\section*{Subquadratic alternatives}

\paragraph{\citet{beltagy2020longformer}.}
Combines local sliding windows with global tokens for linear-ish patterns.
Read it for fixed sparse patterns (Chapter~\ref{ch:sparse}).

\paragraph{\citet{zaheer2020bigbird}.}
Random + window + global sparse attention with theoretical connectivity claims.
Read it as another classic fixed-pattern design point.

\paragraph{\citet{gu2021s4}.}
Structured state-space sequence layer with stable parameterisation and long
range. Read it for the SSM revival before selection and hardware-aware scans.

\paragraph{\citet{gu2023mamba}.}
Selective SSM with input-dependent dynamics and efficient parallel scan. Read
it for state-space models as a real transformer competitor on throughput.

\paragraph{\citet{poli2023hyena}.}
Long convolutions and implicit filters as attention replacements. Read it for
the convolution / spectral quadrant of the map in Chapter~\ref{ch:quadrant}.

\paragraph{\citet{katharopoulos2020linear}.}
Linearised attention via kernel feature maps and recurrence. Read it for the
``linear attention'' quadrant without necessarily going all the way to SSMs.

\paragraph{\citet{choromanski2021performer}.}
Random-feature approximation for softmax-kernel attention. Read it when you
want rigorous sampling-based approximations rather than heuristic sparsity.

\paragraph{\citet{sun2023retnet}.}
Retention-style recurrence connecting attention and state-space views. Read it
for hybrid perspectives that blur the subquadratic-alternative categories of Chapters~\ref{ch:sparse}--\ref{ch:hybrids}.

\section*{Hybrids and the new wave}

\paragraph{\citet{lieber2024jamba}.}
Alternates transformer layers with Mamba blocks for throughput--quality trade-offs.
Read it as a systems-grounded hybrid datapoint.

\paragraph{\citet{ren2024samba}.}
Combines Mamba with sliding-window attention for long context. Read it when you
want selective sparse routing plus local attention baselines.

\paragraph{\citet{de2024griffin}.}
Gated linear recurrences with local attention in a practical LM recipe. Read it
for ``RNN flavour'' hybrids that still train like modern stacks.

\paragraph{\citet{deepseek2024dsa}.}
DeepSeek's sparse attention mechanism with empirical long-context results. Read
it when placing ``DSA'' on the routing/subquadratic map (Chapter~\ref{ch:ssa}).

\section*{Evaluation}

\paragraph{\citet{hsieh2024ruler}.}
Synthetic multi-task long-context benchmark with controllable length. Read it
for methodology discipline---what ``passes RULER'' does and does not prove.

\paragraph{\citet{liu2024lostmiddle}.}
Shows U-shaped utilisation of context in needle-style tasks. Read it as the
counterweight to raw context-length marketing.

\paragraph{\citet{chen2025mrcr}.}
Multi-round conversational retrieval stress test. Read it for evaluation that
targets agentic repetition and recall rather than single-shot retrieval.

\section*{What might come next}

\paragraph{\citet{lecun2022jepa}.}
World-model flavour of representation learning via latent prediction. Read it
when asking whether next-token LM is the only game in town for intelligence.

\paragraph{\citet{lou2024discrete}.}
Discrete diffusion over tokens as an alternative generative factorisation. Read
it for non-autoregressive decoding angles touched on in Chapter~\ref{ch:post-attention}.

\paragraph{\citet{yao2023react}.}
Interleaves chain-of-thought reasoning with tool actions in text form. Read it
for how ``LM + retrieval/tools'' reframes scaling limits without changing the
base model family---complementary to architectural attention debates.
